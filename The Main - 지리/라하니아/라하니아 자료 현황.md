# 라하니아 자료 현황

라하니아 판을 그리고 구조를 정하기 전에, 이미 있는 자료를 모아 둔 표예요. **새로 정한 내용은 없어요.**

**표시**
- **작가 확정**: 대화나 작가 답변에서 확정된 것
- **정리본**: 2026-09-30에 작가가 검토한 정리본
- **원문 조각**: 옛 OneNote 노트. 정리되지 않은 조각이에요.
- **노션 상태**: 설정집 상태값. 라하니아 관련 페이지는 전부 「원문 정리」나 「초안 보존」이고, 「현재 설정」은 하나도 없어요.

**경로 약칭**
- `N/` = 본 보관소 `MN-Node/`
- `C/` = 본 보관소 `MN-Core/`

## 한눈 요약
- 라하니아 전용 노트는 짧은 원문 조각 6개뿐이에요(`N/Speril/라하니아/`).
- 작가가 새로 확정한 문장은 하나뿐이에요. "어브릴을 아는 스퍼릴은 극소수라 라하니아에서 잘 지냈다"는 줄이에요.
- 지도에서 확정된 건 위치 하나예요. 세계 지도에서 어브릴 북쪽의 큰 영역이에요.

## G. 서로 다르게 적힌 것
1. **라하니아가 무엇인지**가 엇갈려요. 노션은 판정을 보류했어요.
   - 스퍼릴 12종 중 하나
   - "스퍼릴 즉 라하니아" (스퍼릴 전체와 같다는 뜻)
   - "스퍼릴의 라하니아 출신" (지명)
   - 정리본: "국가이자 종족(귀멸인)"
2. **귀멸인 = 라하니아인지**: "라하니아(귀멸인)" 표기와 노트 제목 「스퍼릴 (귀멸인)」이 엇갈려요. 귀멸인의 땅은 LER에서 "인계"라고만 불러요.
