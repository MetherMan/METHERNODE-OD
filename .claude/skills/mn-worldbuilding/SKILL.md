# 메러노더(METHERNODE) 작업 규칙

메러노더는 작가(사용자)가 2018년부터 만든 자기 세계관이에요. 작가는 이 세계에 깊이 빠져 있고, 틀린 해석을 금방 알아봐요. 이 스킬은 어느 작업대(폴더)에서 시작하든 같은 규칙을 지키려고 만든 거예요. 작가가 규칙을 고치면 **이 파일도 같이 고쳐요** (`C:\Users\dayba\.claude\skills\mn-worldbuilding\SKILL.md`).

## 1. 작가와 일하는 법
- 모든 대답과 보고는 **한국어**로 해요. 긴 작업 끝 보고에서 영어로 새기 쉬워요.
- 이야기·설정·지역·인물 설계는 **작가가 해요**. 요청받은 것만 구현하고, 묻지 않은 설정 아이디어를 계속 내밀지 않아요. 아이디어는 요청받을 때만 내요.
- **미정은 미정으로 둬요.** 빈 곳을 추측으로 채우지 않고 "미정"이라고 표시한 뒤 작가에게 물어요.
- 작가가 확정한 것과 내 제안은 항상 따로 써요. 제안은 "미채택 제안 / 초안"으로 남기고, 확정되기 전엔 정식 설정처럼 쓰지 않아요.
- 작가가 싫어한 것: 짜깁기, "짜침", 가볍고 편의적인 새 장치, 표만 잔뜩 있는 딱딱한 설명, 숫자 버프(+2/−3) 식 설계.
- 작가가 좋아한 것: "와 미친 논리" — 이미 정한 규칙에서 저절로 따라 나오는 결과. 논리 시험을 할 땐 **규칙이 강제하는 것 / 내가 고른 것 / 작가가 정할 값**을 나눠 보여 줘요. 내 편하게 맞추지 않아요.
- 설정 문장(노트에 들어갈 글)이나 의견이 필요하면 Sonnet 에이전트에게 독립적으로 맡길 수 있어요(작가가 "보통"이라 하면 effort medium). 결과는 내가 설정·용어를 검토한 뒤 써요.

## 3. 원문 조각은 기초가 아니에요
- 원문 노트(OneNote에서 온 것)는 **정리되지 않은 조각**이에요. 미정이 많고, 옛 판과 새 판이 섞여 있어요.
- 새 기초(체계·규칙·문화)를 만들 때 원문 조각을 재료나 예시로 끌어오지 않아요. 작가: "저건 지금 정리된 문서가 아니라서 가져오면 안 된다… 우리는 기초를 창조하는 과정에 있다."
- 기초는 **작가가 확정한 것 + 논리**로 만들고, 원문은 나중에 어긋나는지 확인할 때만 봐요.
- 자료를 조사·정리할 땐 원문도 읽되, 출처마다 **정리본 / 확정 / 초안 / 원문 조각** 표시를 붙여요.

## 4. 기록 규칙
- **P번호(원문번호)는 어디에도 보이지 않게** 해요 (파일 이름, 속성, 목차, 내 글). 원문은 노트 이름이나 링크로 가리켜요.
- 작가 전용 비밀은 접는 칸 `> [!mn-spoiler]- 작가 전용 · …` 에 넣어요.
- 노트 속성은 노션 속성과 맞춰요: `분류`, `상태`, `원전`, tags.
- 일반 단어(형식·영역·살기·생기)에는 링크를 걸지 않아요.
- 노션과 Obsidian 중 한쪽만 고쳤으면, 어느 쪽이 최신인지 보고에 적어요.

## 5. 용어 규칙
- 다섯 근간: **허원(무) · 종명 · 고형 · 계연(닻) · 심위**. 쉬운 이름은 무·닻 둘뿐이에요. 명·꼴·켜·홈·그릇 같은 줄임말은 절대 쓰지 않아요.
- **포빌** = 보조적 기운 가운데 고대전쟁 이후 잊힌 것. 정의를 바꿔 해석하지 않아요.
- **설계설**(흑장설·재백설·적패설·악구설·세계설)은 학파도, 세계 안의 경전도 아니에요. 작가가 독자에게 주는 설명 깊이의 사다리예요(흑장설이 가장 깊고 세계설이 가장 쉬움).
- 다섯 학파(본연·정식·의존·인과·지맥)는 **폐기**됐어요(2026-10-08). 학문은 "OO학은 ~하기 위한 학문"처럼 목적으로 정의하고, 서로 싸우는 학파로 그리지 않아요.
- 투력 등위(2026-10-08 새 이름): **미력 · 일반 · 은 · 귀 · 화명 · 신료 (+ 논외)**. 새 등위의 수치 범위는 아직 안 정해졌어요. 옛 OneNote 표에서 끌어오지 않아요.

- **문명 수준** (작가 확정 2026-10-19): 중세 판타지가 아니에요. **메러노더스럽게, 판타지스럽게 고도화된 발전**이에요. 기계도 있어요. 플라즈마로 통화를 하거나 영상 매체를 보는 것도 충분히 가능해요. 과학·공학의 발전만으로도 고투력자에게 맞설 수준이라 기술도 아득히 높아요. 그렇다고 **영화 속 SF 느낌은 아니에요**. 성벽·요새 같은 중세 도시를 기본으로 깔지 않고, 네온·금속 고층·우주선 같은 SF 겉모습도 쓰지 않아요. 구체적인 모습(교통·건물·도시 구조)은 미정이니 작가에게 물어요. 자료에는 거의 없고, 4간구 종족 표에 헤이머스 = "과학기술·공학기술이 뛰어난 문명 발단국" 정도가 있어요.
- **수도**: 라그놀리아의 수도는 **라그리아**(정리본·외전 원문). 라하니아 수도는 자리만 정해졌고(라하니아 판, 작가 표시) 이름은 미정이에요.
- **비밀**: 어브릴은 고대전쟁 이후에 갈라져 나온 종족들이에요 (작가 전용, 노트에는 mn-spoiler 칸에).
- 라그놀리아는 작가가 잘 알아요. 라그놀리아 정리는 작가가 따로 원하지 않으면 손대지 않아요.
- 존재 위계: 생체 < 지성체(어브릴 < 스퍼릴) < 자립체 < 신성체 < 신격체 … 마녀·악마는 최상위급 반(反)플라즈마 존재예요. 작은 사건에 끌어오지 않아요.
- 투력은 비선형이에요. "두 배 강함"이 100 대 130, 2,000 대 2,200, 17만 대 18.1만 정도예요.
- 보통 라그놀리아 인간 300~600. 1,000쯤이면 랭커(신기 있음)이고 보통 사람은 못 따라와요. 무전 학생은 C반에서 1,000쯤에 졸업해 랭커가 돼요. 2,600이면 베테랑이에요.
- 60만 벽 = 어브릴/스퍼릴 종족 차이(스퍼릴은 신위를 갖고 태어나요).
- **주인공(Mely 등)은 기준이 아니에요.** 비기·오의·극의·비의, 공괴, 모디드(보통 4,900쯤 익혀 5,500 벽을 넘음)는 별 중의 정점이에요. 보통 사람·플레이어 기준은 일반 인구 설정(등위 도감, 무전 학생, 랭커 생계수단, 미력자)에서 잡거나 작가에게 물어요. 반대로 너무 낮게 잡지도 않아요.

## 7. 세계판 플러그인 (MN 실험실)
- `.obsidian/plugins/mn-sekaipan/` (빌드 없는 CommonJS `main.js` + `styles.css`). 사용법은 보관소 맨 위 `The Guide - 시작.md` — 기능을 바꾸면 같이 고쳐요.
- 노트 속성이 곧 데이터예요.
  - 지역: `분류: 지역`, `지도`, `좌표: [x, y]`(지도 그림 픽셀), `상위: "[[…]]"`, 넓은 땅이면 `표식: 영역`
  - 인물: `분류: 인물`, `위치: "[[지역]]"`, `하는 일`, `시점`, `초상: "[[그림]]"`
- 땅 칠하기 데이터: `The Archive - 자료/4간구.영역.json`
- **지형 그리기** (v0.4, 2026-10-19): 작가가 지도를 직접 그려요. 땅·바다·숲은 붓, 영역(어브릴·라하니아 등)은 꼭짓점 다각형. 해안 굴곡·물결선·숲 테두리·영역 띠는 그림에 맞춰 플러그인이 다시 그림(4간구 양식, Opus 미술 검토 수치). 데이터 `The Archive - 자료/메러노더.지형.json`, 구운 그림 `The Archive - 자료/메러노더.jpg`, 밑그림 `The Archive - 자료/MN2.jpg`. 지도 모양을 내가 지어내지 말고, 고칠 일은 이 도구로 작가가 하게 해요.
- 보관소 폴더 이름은 숫자 없이 격식 있게: `The Archive - 자료` · `The Main - 지리` · `The Main - 인물` · `The Rule - TRPG` · `The Guide - 시작.md` (작가 지시 2026-10-19). 새 폴더도 이 꼴로 지어요.
- 판 타고 들어가기(v0.5): 보기에서 영역을 누르면 그 영역의 판으로. 판은 지형 그리기 → 영역 → 「판 만들기」로 생기고, 판 목록은 `.obsidian/plugins/mn-sekaipan/data.json`(maps의 parent·region). 지금 판: 메러노더 전체 › 라하니아.
- 펼쳐지는 마을(v0.6, 시험 마을 입체 그림책): 페이지는 `.도구/창/popup/index.html` 하나이고, 세계판 창(`/popup/index.html`)과 Obsidian 플러그인 화면 「펼쳐지는 마을」(액자로 띄움, `?obs=1` — 보관소 읽기·쓰기는 postMessage로 플러그인이 대신)이 같이 써요. 저장은 `The Archive - 자료/마을 (시험).마을.json`(지역 = 마을의 장면, 지역의 `stages` = 그 장면 안의 장소(골목길 · 거리)로 따로 새로 꾸미는 판 {name, parent, w, h, floor, items(그 판 좌표)}, 건물·사람·기관 카드). 기록은 종류별 노트(세션 → `The Rule - TRPG/기록/세션/`, 사건·메모 → `The Main - 지리/펼쳐지는 마을/`, 속성 `분류: 기록` · `자리`), 카드 노트는 `분류: 그림책`. 펼치면 위에서 보는 그림책이고, 건물 · 사람을 누르면 카메라가 그 앞 눈높이로 와서 보여 줘요(들여다보기 · 작가가 마음대로 걷는 1인칭보다 이쪽을 골랐음, 걷기는 덤으로 W A S D · V · 판 둘레 나무 울타리 · 멀리 두른 풍경 막 · 3D 종이 구름과 해는 1인칭 전용 무대 소품이라 저장 안 함. 먼 풍경을 판 가장자리에 붙이거나 하늘을 화면에 붙이면 어색하다고 했음). 때(낮 · 노을 · 밤)는 저장본의 `time`. 스테이지 이름·기록·카드 내용은 작가가 정해요(내가 채우지 않음). 화면이 그림을 버리는 문제는 GPU 메모리 부족이라, 고치면 `--force-gpu-mem-available-mb=64` 크롬으로 시험해요.
- 작가는 Obsidian 대신 Claude 앱 브라우저의 세계판 창(http://localhost:8732, `.도구/창/serve3.py`)에서 그리기도 해요. 그 서버를 끄거나 창을 새로 고치기 전에 그리던 게 저장됐는지 꼭 확인해요.
- 방향: 작가 혼자 쓰는 세계관 완성 도구 + 시뮬레이터예요(플레이어용 아님). 시뮬 결과는 노트에 쓰지 않고 따로 저장해요. 행동지침 시스템은 작가가 다시 꺼낼 때까지 보류예요.
