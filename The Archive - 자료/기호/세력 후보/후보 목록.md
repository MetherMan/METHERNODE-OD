# 세력 심볼 후보

지도에 건물 대신 놓을 세력 심볼 후보예요. **작가가 아직 고르지 않았어요.** 고른 것만 나중에 `기호/세력`으로 옮겨요.

- 지도에는 메달 모양(먹빛 원판 + 놋쇠 테 + 상아색 문양)으로 72px쯤 크기로 놓을 생각이에요. 파일마다 먹 원화(흰 바탕)와 `(메달)` 그림이 짝이에요.
- 그림은 Codex 이미지 생성으로 그리고, 코드로는 손질만 했어요(왕관 수 맞추기, 반짝이 지우기, 칼 기울이기, 바탕 정리, 메달 만들기). 모두 Opus 미술 검토를 거친 것만 남겼어요.

## 케이숑의 기사

작가가 준 재료: **여신의 옆모습 · 흩날리는 깃발 · 기사의 검**.

| 후보 | 구도 | 메모 |
|---|---|---|
| A 칼 세움 | 세로 검 한가운데, 왼쪽을 보는 여신, 칼날에 묶인 천이 오른쪽으로 | 작가: 칼을 너무 정직하게 두지 말 것 |
| B 깃대가 된 검 | 비스듬히 세운 칼이 깃대, 깃발 안에 옆얼굴을 하얗게 파냄 | 검토: 72px에서 깃발로 바로 읽히는 유일한 안 |
| C 받침이 된 검 | 왕관 쓴 여신 아래로 칼을 가로로 눕히고 천을 걸침 | 반짝이를 둘로 줄임. 칼이 수평이라 정직해 보일 수 있음 |
| D 아치와 두루마리 | 고딕 아치 안의 여신, 칼은 아치 뒤로 비스듬히, 아래 두루마리 | 고전 문장형. 두루마리 빈칸은 검게 메움 |

- 작가 (2026-10-26): 여신이 순해 보이지 않고 **표독해 보임**. 순한 얼굴로 다시 그릴 예정이에요.

## 레스델니온

왕관 8개 + 검.

| 후보 | 구도 | 메모 |
|---|---|---|
| A 칼 세움 | 세로 검, 둘레에 왕관 8개 (좌우 4개씩) | 시안의 왕관 10개를 8개로 고침 |
| B 치켜든 검 | 칼끝이 위로 비스듬, 왕관 빈자리도 칼을 따라 돎 | 원 + 사선이라 얼핏 금지 표지로 보일 수 있음 |
